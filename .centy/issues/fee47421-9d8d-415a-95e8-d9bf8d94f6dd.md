# Consume Centy MCP over the daemon's stateless HTTP endpoint

## Summary

Centy MCP is consumed only through the daemon's built-in endpoint `http://127.0.0.1:50052/mcp`. Clients no longer start a process (`npx centy-mcp`, a local `centy-mcp` binary). The endpoint is stateless: every request stands alone, with no session id or handshake.

## Why

The npx bridge failed on cache corruption, drifted out of version with the daemon, and needed a separate npm release. A URL served by the daemon removes all three problems.
